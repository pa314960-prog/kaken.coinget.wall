# シルエットコインたたき

🎮 公開URL: https://pa314960-prog.github.io/kaken.coinget.wall/

カメラに映った自分の影（シルエット）がそのままプレイヤーになり、
落ちてくるコインを手で弾き飛ばすブラウザゲームです。
USJ のクッパ Jr. ファイナルバトルのように、プレイ中は実写映像ではなく、
明るいステージの上に自分が真っ黒な影として映し出されます。

- 制限時間60秒。落ちてくるコインを手で弾き飛ばすとスコア加算
- **勢いよく弾くほど高得点**（手が速く動いているほど倍率が上がる）
- **床に落とす前に空中で連続して弾くとコンボ**（最大5倍）
- 弾いた回数が10回たまるごとに BIG 状態（8秒間、得点2倍・影とコインが金色に光る）
- 感度と落下速度をスライダーで調整可能

ビルド不要・依存ライブラリ無し（Vanilla HTML/CSS/JS）で作っているため、
Windows / Mac / Linux のどの PC でも、ブラウザとローカル HTTP サーバー
さえあればそのまま動きます。

現在の実装状況は [PROGRESS.md](./PROGRESS.md) を参照してください。
Stage 1〜3（カメラ取得・背景差分マスク・ゲームロジック）すべて実装済みで、
一通り遊べます。

---

## 1. 動作環境（Windows での前提）

- Windows 10 / 11
- カメラ付き PC、または USB カメラ
- 最新版の Google Chrome または Microsoft Edge（推奨）

カメラ機能 (`getUserMedia`) はブラウザの仕様上、
**`http://localhost` または `https://` 経由でアクセスした場合のみ**
動作します。`index.html` をダブルクリックして `file://` で開いても
カメラは起動しませんので、必ず下記の手順でローカルサーバーを
経由してアクセスしてください。

---

## 2. Windows でこのゲームを動かす手順

### 手順 A: リポジトリを取得する

Git がインストール済みの場合、PowerShell で以下を実行します。

```powershell
git clone https://github.com/pa314960-prog/kaken.coinget.wall.git
cd kaken.coinget.wall
git checkout claude/silhouette-coin-game-r0b6od
```

Git を使わない場合は、GitHub の "Code" → "Download ZIP" から
ダウンロードして展開してください（ブランチを
`claude/silhouette-coin-game-r0b6od` に切り替えるのを忘れないでください）。

### 手順 B: ローカル HTTP サーバーを起動する

どちらか使える方法で構いません。

**Python がインストール済みの場合（推奨・追加インストール不要なことが多い）**

```powershell
cd kaken.coinget.wall
python -m http.server 8000
```

**Node.js がインストール済みの場合**

```powershell
cd kaken.coinget.wall
npx serve -l 8000
```

Python も Node.js も無い場合は、
[Python公式サイト](https://www.python.org/downloads/) からインストーラーを
ダウンロードしてインストールしてください（インストール時に
「Add python.exe to PATH」にチェックを入れてください）。

### 手順 C: ブラウザで開く

ブラウザで次の URL を開きます。

```
http://localhost:8000/
```

### 遊び方（画面上のボタンを上から順に押すだけ）

1. **① カメラ開始**を押す。ブラウザ上部にカメラ利用許可の確認が出るので
   **「許可」をクリック**してください。自分の姿が鏡のように左右反転して
   表示されれば成功です。
2. **画面から自分が外れて**（一歩下がる、フレームアウトするなど）から、
   **② 背景を記憶**を押してください。これで「自分がいない状態」の映像を
   基準として覚えます。ここが最も重要な UI 操作です。
   - うまく反応しない場合は、下の「感度」スライダーを調整し、
     チェックボックスにチェックを入れて、自分の輪郭に緑色のマスクが
     追従するか確認しながら調整してください。
3. 画面内に戻り、**③ ゲーム開始**を押すと60秒のゲームが始まります。
   ここから先は USJ のクッパ Jr. ファイナルバトルのように、
   **実写のカメラ映像は表示されなくなり**、明るいステージ背景の上に
   自分が真っ黒な影として映し出されます。
   落ちてくる🪙(コイン)を**手で払うように弾き飛ばして**ください。
   - 弾いたコインは手を動かした向きへ飛び、上に跳ね上がります。
     **手を速く動かすほど高得点**です。
   - コインが床に落ちる前にもう一度弾くと**コンボ**になり、
     倍率が x2, x3… と上がります（最大 x5）。連続で打ち上げ続けるのが
     いちばん点を稼げます。
   - 弾いた回数が10回たまるごとに BIG 状態（8秒間、得点2倍・
     自分の影とコインが金色に光る）になります。
   - コインは左右の壁と天井で跳ね返るので、画面の端でも狙えます。
4. 60秒経過するとゲーム終了画面が出ます。「もう一度プレイ」で
   同じ背景のまますぐ再挑戦、部屋の明るさが変わった場合などは
   「背景を撮り直す」を押してから②からやり直してください。

落下速度・感度はスライダーでゲーム中もいつでも調整できます。
サーバーを止めたいときは、PowerShell のウィンドウで `Ctrl + C` を
押してください。

### 次回以降の起動方法

1. `kaken.coinget.wall` フォルダに移動する。
2. 手順 B のコマンド（`python -m http.server 8000` など）を実行する。
3. ブラウザで `http://localhost:8000/` を開く。

これだけです。インストール作業は初回のみで、2回目以降は
サーバー起動とブラウザアクセスだけで動きます。

## 3. Claude Code をローカルで実行して開発を続ける場合

このリポジトリの `PROGRESS.md` には、Claude（AI エージェント）が
次に何を実装すべきかを読み取れる形で進捗と手順を書いています。
Windows のご自身の PC で Claude Code CLI を動かし、この
`PROGRESS.md` を読み込ませることで、開発の続き（Stage 2, Stage 3）を
ローカルで進めることができます。カメラを使った動作確認はご自身の
PC でないとできないため、この方法がおすすめです。

### インストール（初回のみ）

1. [Node.js](https://nodejs.org/)（LTS版）をインストールする。
2. PowerShell で以下を実行し、Claude Code CLI をインストールする。

   ```powershell
   npm install -g @anthropic-ai/claude-code
   ```

3. インストール後、以下でバージョンが表示されれば成功です。

   ```powershell
   claude --version
   ```

4. 初回起動時に Anthropic アカウントでのログインを求められるので、
   画面の指示に従ってログインしてください。

   ```powershell
   claude
   ```

### このリポジトリを Claude Code に読み込ませて続きを実装させる

```powershell
cd kaken.coinget.wall
git checkout claude/silhouette-coin-game-r0b6od
git pull
claude
```

`claude` 起動後、チャットで例えば次のように依頼してください。

```
PROGRESS.md を読んで、現在の実装状況を確認してください。
Stage 2（背景記憶ボタンと背景差分マスクの可視化）を実装してください。
実装後、ローカルサーバーの起動方法と確認手順を教えてください。
```

Claude Code が実装を終えたら、指示に従ってローカルサーバーを起動し、
実際にブラウザで動作確認をしてください。問題なければ、
Claude Code に Stage 3 の実装を依頼してください。

### 次回、開発を再開するとき

同じフォルダで `claude` を実行すると、そのフォルダの会話・作業内容を
再開できます（フォルダを移動していなければ自動的に続きから始まります）。
セッションを明示的に再開したい場合は次のように実行してください。

```powershell
cd kaken.coinget.wall
claude --continue
```

新しくブランチが進んでいる場合は、事前に `git pull` を忘れずに
行ってください。

## 4. 必ず必要になる UI 操作（重要）

- **「② 背景を記憶」を押す瞬間は、必ずプレイヤーが画面に映っていない
  状態にしてください。** これは自動化できません（背景差分の基準画像を
  撮影する処理のため、人が画面から外れるタイミングを判断する必要が
  あります）。
- 部屋の明るさやカメラの位置を変えた場合は、ゲーム終了画面の
  「背景を撮り直す」から背景記憶をやり直してください。
- 感度・落下速度のスライダーは、部屋の明るさやカメラとの距離に応じて
  人が調整する前提です（自動調整はしていません）。

## 5. ファイル構成

```
index.html    ... ゲーム画面の HTML（UI 部分: ボタン・スライダー・HUD）
game.js       ... ゲームロジック本体（カメラ/背景差分/弾き飛ばし/スコア等）
PROGRESS.md   ... 実装の進捗・改善候補の記録（AI 引き継ぎ用）
README.md     ... このファイル（セットアップ手順）
```

修正しやすいように、HTML(UI) と JS(ロジック) を分離し、
`game.js` 内は Stage 1 / Stage 2 / Stage 3 のセクションコメントで
区切っています。主な調整ポイントは以下の変数です（`game.js` 冒頭〜中盤）。

- `PROC_W` / `PROC_H`: 背景差分の計算解像度（重い場合は下げる）
- `COIN_SCORE`: 1回弾いたときの基準点
- `COMBO_MAX`: 空中コンボ倍率の上限
- `BIG_EVERY_N_HITS` / `BIG_DURATION_MS`: BIG状態の発生条件・持続時間
- `FLING_UP_MIN` / `FLING_UP_MAX`: 弾いたときに上へ跳ね上がる速さ
  （もっと勢いよく飛ばしたい場合はここを上げる）
- `FLING_SIDE_MAX`: 手を動かした向きへ飛ぶ横方向の速さ
- `MOTION_FULL_POWER_RATIO`: 手の動きへの反応しやすさ
  （弾いても勢いがつかない場合は下げる）
- `MASK_CLOSE_RADIUS` / `MASK_MIN_BLOB_PX`: 影の穴埋め・ノイズ除去の強さ
